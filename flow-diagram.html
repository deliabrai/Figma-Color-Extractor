Figma Color Extractor — Flujo de 7 pasos

Este diagrama forma parte de un proyecto de clase del monográfico de IA para Diseñadores en SHIFT+R.

El objetivo es explicar cómo se construyen infraestructuras de Context Engineering: la colaboración entre un Agent, Skills y MCPs para automatizar flujos de trabajo en Figma.

Detalle de cada capa
AGENT — Pasos 1, 2, 3, 7b
  • Parsea URL → extrae fileKey y nodeId
  • Convierte - → : en el nodeId
  • Detecta 3 colores dominantes del screenshot
  • Color primario (más dominante / de marca)
  • Color de acento o fondo
  • Color de texto o neutro
  • Calcula 36 tokens OKLCH con oklch.js
  • Genera color-palette.html con CSS vars
  • Abre el HTML en el navegador
MCP — Pasos 4, 5, 6, 7a
  • figma_execute → navega a la página
  • getNodeByIdAsync(nodeId)
  • setCurrentPageAsync(page)
  • figma_setup_design_tokens → colección brand-colors
  • Modo: Value · 36 tokens
  • figma_execute → 12 RECT 140×140px por rampa
  • Fill vinculado a variable con setBoundVariableForPaint
  • Etiquetas: número de paso + hex
  • 3 FRAME "Color Ramp / nombre"
  • figma_capture_screenshot → validación visual
SKILL — Paso 0 (protocolo)
  • Define los 7 pasos en orden estricto
  • Fórmulas OKLCH (L: 0.97 → 0.20)
  • Nomenclatura: <color>/<step>
  • Referencia a scripts y templates
  • Quién hace qué: AGENT / MCP / SKILL
Nomenclatura de tokens
  • Formato: <color-name>/<step>
  • Ej: blue/50 · blue/100 … blue/950
  • Ej: coral/50 … coral/950
  • Ej: slate/50 … slate/950
  • Colección Figma: brand-colors
  • Usa nombre real del color detectado
  • NO usar primary/secondary/tertiary
Archivos de salida
  • color-palette.html en la raíz
  • Número consecutivo en el nombre
  • No crear subdirectorios
  • Script: scripts/oklch.js
  • Script: scripts/figma-swatches.js
  • Template: scripts/web-template.md
MCPs usados en este proyecto
  • project-figma-console — escritura en Figma (instancia aislada del proyecto)
  • user-figma-remote — lectura de Figma: get_design_context, get_screenshot
  • user-exa — búsqueda web semántica para investigación
¿Qué es MCP?

El Model Context Protocol es un estándar abierto de Anthropic (nov 2024) que conecta agentes de IA con herramientas externas — bases de datos, APIs, editores — de forma estandarizada, como un "USB-C para la IA".
